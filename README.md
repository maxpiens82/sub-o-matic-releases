# Sub-o-matic: instaladores

**Cómo funciona, con capturas y un recorrido animado:** https://maxpiens82.github.io/sub-o-matic-releases/

Acá están solo los instaladores de Sub-o-matic, la app de Re! para subir los crudos de las
tarjetas al Drive. El código no está en este repositorio.

## Instalar

1. En **Releases** (a la derecha), abrí la última versión y bajá `Sub-o-matic-Setup-….exe`.
2. Abrilo. Si Windows muestra "Windows protegió tu PC", tocá **Más información** y después
   **Ejecutar de todas formas** (pasa solo la primera vez: la app no tiene firma digital).
3. Se instala sola y se abre. Ingresá con tu cuenta de Google de Re!.

Después se actualiza sola: baja la versión nueva en segundo plano y la instala cuando no hay
subidas en curso.

Para usarla hace falta una cuenta habilitada en el sistema de Re!.
